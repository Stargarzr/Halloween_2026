## Upload to GitHub

This folder is a complete project. If you use GitHub's **Add file → Upload files** page, upload the **contents of this folder** so this `README.md`, `app`, `components`, `public`, `package.json`, and the other folders sit at the repository root.

Do **not** upload `.env`, `node_modules`, `.wrangler`, `.next`, or `dist`. They contain private settings, locally stored event data, or files that can be recreated with `npm ci` and `npm run build`.
